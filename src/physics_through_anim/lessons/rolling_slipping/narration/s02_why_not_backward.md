# Scene 02 — How Static Friction Responds

Start with no applied force. There is no tendency to slide, so static friction is zero. Now I slowly increase the applied force, and watch the graph.

As the applied force grows, static friction grows with it. Two newtons needs two newtons. Four newtons needs four. Notice that friction is not sitting at its maximum. While the block stays at rest, it adjusts so that f s equals F.

But this cannot continue forever. Static friction has a ceiling, f s max equals mu s N. As the force approaches it, friction approaches its limit, until exactly at the threshold, f s equals mu s N.

So mu s N is not the friction at every instant. It is the maximum available. Static friction takes whatever value is required, from zero up to this limit.
